# ThermaGuard dashboard

The dashboard is built with React and Vite. It includes heat monitoring, alerts, reports, settings, and an intervention planner.

## Start the dashboard

From this folder, run:

```bash
npm install
npm run dev
```

For live weather and saved plans, start the FastAPI service as described in the [project guide](../README.md). The dashboard uses sample data when the service is offline.

## Build and lint

```bash
npm run build
npm run lint
```
